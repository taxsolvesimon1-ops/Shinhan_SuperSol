01 핵심 고객

국내 거래소에서 코인을 사서 2027년 1월 1일 이후에도 갖고 있을 사람이, "나도 세금 내야 하나?" 하고 미루고 있을 때

02 핵심 가치

"내가 신고·납부 대상인지"를 입력값 기준으로 1분 안에 안다 — 판정 카드 + 적용 조건 + 계산 과정 한 줄

03 미션·완료 기준

진입(첫 화면) → 코인 선택·보유 질문·금액 입력 → 결과 화면. 완료 = 결과 화면 도달 + "이해됐나요?" 응답. 중단 = 시작 후 결과 미도달

04 현재 제공 범위

동작: 코인별 입력·손실 통산·취득가액 특례(§37⑤)·50% 의제·판정·세액·기한·기기 저장·FAQ. 가상 체험: 랜딩 30초 맛보기, 앱 예시 2종. 미연동: SOL 딥링크·거래소·지갑(의도적). AI: 서비스 안엔 없음 — 문의 1차 응답·피드백 분류·일일 리포트에 사용

05 체험 환경

웹 shinhan-supersol.vercel.app · 로그인·설치 없음 · 테스트 계정 불필요 · 가상 숫자 "예시로 먼저 해보기" · 문의: 김상문 세무사, 카카오톡 채널

06 슈퍼SOL 기여 가설

기존 고객 재방문 주력 — 세금은 "다음 관련 상황"형: 2027.1.1 전 확인 → 거래 후 재계산 → 2028.5 신고 전. 신규 유입(스레드·유튜브)은 보조로 측정
